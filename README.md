# Multiplex relational event models of self-reported and perceived gossip

This repository contains the code used for the simulation study and empirical application presented in the paper *Multiplex relational event models of self-reported and perceived gossip*.

Traditional relational event models typically focus on a single type of interaction and therefore cannot account for multiple event types that may influence each other over time. We develop Multiplex Relational Event Models (MREMs), an extension of relational event models that jointly models time-ordered events across multiple relational layers. The proposed framework includes endogenous covariates to capture both within- and cross-network effects, together with linear, smooth, and random effects to account for temporal patterns and heterogeneity across classes and individuals. The proposed method is evaluated through simulation studies. Finally, we apply MREMs to longitudinal survey data from secondary schools in Hungary, where gossiping can be viewed as a dynamic multiplex process in which self-reported and perceived gossip interactions coexist and may influence each other over time. Both types of gossip are only partially observed, requiring an extension of the traditional inference procedure. The results illustrate how MREMs can capture the influences of self-reported and perceived gossip on each other and account for both within- and cross-network mechanisms.
